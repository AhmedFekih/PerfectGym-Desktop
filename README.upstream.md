  💪 Plateforme de Gestion de Salles de Sport
Bienvenue sur notre plateforme innovante dédiée à la gestion complète d'espaces sportifs et de bien-être. Cette application offre une expérience fluide pour les utilisateurs, coachs, fondateurs et administrateurs.

Ce projet est encadrée par l université 'Esprit School Of Engineering'

🚀 Fonctionnalités principales
🔍 Recherche de salles de sport
Recherchez des salles selon vos critères : localisation, équipements, offres. Consultez les équipements, abonnements et informations détaillées.



📅 Abonnement et Paiement
Abonnez-vous à une offre.

Paiement en ligne via Stripe.
🧘‍♂️ Coaching & Cours
Interface dédiée aux cours. Inscription aux séances via l'application.

🥗 Nutrition & Repas
Liste de repas sains avec macros nutritionnels.

🎉 Événements sportifs
Consultez et réservez des événements sportifs.

🛒 Produits Sportifs
Boutique dédiée aux articles de sport.

🔐 Gestion des rôles
Rôle	Accès
Fondateur	Création de salles, offres, équipements, événements
Coach	Gestion des cours
Administrateur	Gestion des utilisateurs et produits
Utilisateur	Accès à la plateforme (recherche, abonnement, événements, boutique)

🛠️ Technologies utilisées
Frontend/Backend : Java/JAVAFX
Base de données : MySQL / MariaDB
Paiement : Stripe
Email : Gmail SMTP
QR Code : Génération automatique
Statistiques : Tableau de bord dynamique
PDF : Génération de documents
Notifications : Rappels de cours intégrés

📦 Installation
Clonez le repository :

git clone https://github.com/votre-Utilisateur/Projet-pidev-.git cd pidev

Installez les dépendances :

npm install npm run dev

Configurez la base de données et les variables d’environnement selon fishier.env`.

💻 Utilisation
Accédez à l’interface web via maven . Créez un compte selon votre rôle. Explorez les fonctionnalités selon vos autorisations.
